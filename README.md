# CLSD：稠油注采井连通性智能分析

2026 年中国石油算法挑战赛赛题“稠油注采井连通性智能分析”的决赛方案：**因果滞后谱分段决策模型**（Causal Lag-Spectrum Segmented Decision Model，CLSD）。

仓库包含决赛提交的完整代码与算法说明、决赛补充分析代码（合规核查、补充试验、诊断与答辩图表），以及答辩 PPT 和演讲稿。

## 任务

浅层超稠油靠注汽开采。赛题用“注采响应滞后天数”量化注汽井与生产井之间的连通性：注汽量变化后，采出指标隔多少天跟着变化。

* **输入**：井组信息、注汽日报、采出日报三张表。
* **输出**：对每个（井组，采出指标，日期）给出 0–45 天的整数。采出指标为日产液量、日产油量、含水率、油管压力、井口温度。
* **评分**：分段准确率 60 分（0–3 天为短段，4–45 天为长段），短段误差 30 分，长段误差 10 分。

## 方法

1. **滞后谱**：取预测日之前最近 90 天的注汽与采出，对滞后 0–45 天逐个计算窗内秩相关的显著性（−log10 p），得到一条 46 点的曲线。
2. **特征**：围绕滞后谱构造 924 维特征，只使用预测日及以前的数据。
3. **分段**：两个 ExtraTrees（二分类与 7 类）判断短段还是长段，经固定的逻辑校准得到 P(短段)。
4. **取值**：LightGBM 给出短段内 0–3 天的概率分布。
5. **决策**：按评分规则逐样本取期望代价最小的整数；判为长段时统一输出 4 天。

全流程遵守三条原则：训练只读训练集；特征严格因果；逐样本独立推理。每条原则都有对应的核查脚本。

## 快速开始

1. **准备数据**：从赛事平台获取数据，整理为 `data/train/` 与 `data/test/` 两个目录（文件名与赛事下发的一致）。本仓库不包含比赛数据。
2. **安装依赖**（Python 3.11）：

   ```bash
   cd code
   pip install -r requirements.txt
   ```

3. **训练并预测**：

   ```bash
   python predict.py --data_dir ../data --output ../result/test_optimal_lag_days.csv
   ```

   这条命令会从训练集重新训练模型，保存到 `code/models/model.pkl`，再写出结果文件。之后加 `--use_saved_model` 可以跳过训练、只做推理。其他参数见 `code/README.md` 第 ④ 节。

**复现核对**：在赛事下发的数据和 `requirements.txt` 的依赖版本下，结果文件的 md5 为 `9d7180322d120bdc02d1a233bc849480`，重新训练出的 `model.pkl` 的 md5 为 `766e7f0245a51d18ec90c42f411e9689`，与决赛提交逐字节相同。

## 补充分析与答辩图表

`code/finals_analysis/` 收录决赛阶段为说明方案而写的分析脚本，不参与训练和推理：

* `01_compliance/`：特征因果性、逐样本独立、逐日截断等合规核查；
* `02_experiments/`：跨区块泛化、模型规模、特征族贡献等前向评估补充试验；
* `03_diagnostics/`：决策规则与测试期输出的诊断；
* `04_runtime/`：运行时间与峰值内存测量；
* `05_figures/`：画出答辩 PPT 中的 18 张数据图（另需 matplotlib）。

用法见 `code/README.md` 第 ⑥ 节。
